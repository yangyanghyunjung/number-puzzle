# 🧩 25 Puzzle Game (Console Edition)   


## 📌 프로젝트 소개

이 프로젝트는 C++로 개발된 **콘솔 기반 숫자 퍼즐 게임**입니다.  
**5x5 퍼즐판**에서 1부터 24까지의 숫자와 빈 칸(BLANK)을 **방향키(WASD)**를 사용해 움직이며 정렬하는 게임입니다.

## 📚 프로젝트 목적 (학습 배경)
이 프로젝트는 **정보처리산업기사** 자격증을 준비하면서 **C++** 문법과 구조적인 사고를 익히기 위한 연습용 프로젝트로 진행되었습니다.


## 🎮 게임 규칙 및 목표

- 1부터 24까지의 숫자와 빈칸이 섞여 제공됩니다.
- **숫자 타일을 움직여서** 1부터 24까지 순서대로 정렬하면 게임 클리어!
- 마지막 칸은 항상 **빈칸**이어야 합니다.
- 퍼즐은 사용자가 입력한 횟수만큼 랜덤하게 섞입니다.


## 🕹️ 조작 방법

| 키보드 입력 | 동작 설명     |
|-------------|----------------|
| `W`         | 위로 이동 (↑)  |
| `S`         | 아래로 이동 (↓) |
| `A`         | 왼쪽으로 이동 (←) |
| `D`         | 오른쪽으로 이동 (→) |
| `X`         | 게임 종료       |

- 퍼즐을 움직이기 위해서는 빈 칸(`_`)과 방향이 맞아야 합니다.
- 움직일 수 없는 방향으로 입력하면 무시됩니다.


## 🔄 셔플 알고리즘

퍼즐을 섞는 과정에서는 무작위 방향을 선택하여 빈 칸을 이동시키는 방식으로,  
**Fisher-Yates 알고리즘**의 아이디어를 활용해 자연스러운 난수 기반 섞기를 구현했습니다.  (완전한 Fisher-Yates는 아님)

## 📘 프로젝트를 통해 배운 점 (C / C++)

### ✅ C/C++ 문법 및 구조적 특징

| 개념 | 배운 점 |
|------|---------|
| `#include` | 전처리기 단계에서 시스템 헤더 파일을 가져와 다양한 기능을 사용할 수 있음. (파일 전체 copy & paste한 것과 같은 효과) |
| `using` | 네임스페이스를 생략하고 사용할 수 있게 함 (ex. `using std::cout` |
| `#define` | 매직 넘버나 상수를 정의할 때 사용해 가독성과 유지보수성을 높일 수 있음. 예: 방향 이동값 |
| `enum` | 방향(DIRECTION)을 상수화하여 코드의 의미 전달력을 높이고, 실수 방지 |
| `switch-case` | 여러 분기 처리 시 if보다 더 직관적인 제어 흐름 방식으로 활용 |
| `srand(time(NULL))` | seed(난수 시작값)가 같으면 매번 같은 순서의 결과가 나옴 ->  매번 달라지는 시간 이용|
| 배열 인덱스 | 배열의 인덱스 == 메모리의 시작 주소로 부터 떨어진 거리 |
| `system("cls")`, `Sleep()` | Windows API를 활용한 콘솔 제어 방법 (UI 리프레시, 애니메이션 느낌 주기) |
